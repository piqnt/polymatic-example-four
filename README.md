# Four Game - Polymatic Example

Implemented using:
- [Polymatic](https://github.com/piqnt/polymatic) framework
- [Stage.js](https://github.com/piqnt/stage.js) rendering engine
- [Preact](https://preactjs.com/) and [Preact Signals](https://github.com/preactjs/signals)

[Play Live Demo](https://piqnt.com/4/four/)

### How to play

Connect circles to make a *sequence* of four different colors.

White is wildcard, it can be used instead of any other color.

Black is bomb, it removes connected circles, up to three circles away.

### How to run the code

To run or build the source code in this repository you need to have node.js/npm installed.

Install this project dependencies:

```sh
npm install
```

To run the project locally:

```sh
npm run dev
```

This will print out the url where you can open the project.

To build the project for production:

```sh
npm run build
```
